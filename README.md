# Reserva em Pé — Justiça Climática

Site educativo sobre justiça climática no Acre, com o jogo de simulação **"Reserva em Pé"**, onde cada personagem faz sua parte para salvar a floresta.

🔗 **Jogar:** https://jailanne-maria.github.io/justica-climatica/

## O que tem aqui

- **index.html** — site explicativo (justiça climática, El Niño, CadÚnico, Rio Branco)
- **jogo.html / jogo.js / jogo.css** — jogo de simulação 2D (12 anos, 4 personagens)
- **jogo3d.html / jogo3d.js / jogo3d.css** — versão 3D do jogo (Three.js)
- **sobre.html** — página sobre o projeto

## Sobre o jogo

Em uma simulação de **12 anos**, você alterna entre 4 personagens que vivem a floresta de formas diferentes:

| Personagem | Papel | Exemplo de ação |
|---|---|---|
| 🥥 Dona Marinalva | Extrativista | Colher castanha, fazer empate, plantar mudas |
| 🐟 Seu João | Ribeirinho | Pescar com manejo, proteger igarapés, vigiar queimadas |
| 🏫 Guajarina | Amazônia urbana | Aula de educação ambiental, organizar mutirão |
| 🐝 (4º personagem) | — | — |

Cada ação afeta indicadores da floresta (extrativismo, ribeirinho, urbano, apoio, pressão) — ensinando, na prática, que **justiça climática se constrói com a floresta em pé e com as comunidades fortalecidas**.

## Como rodar localmente

Abra o `index.html` no navegador — roda 100% no browser, sem servidor. Para o login com Google, configure o `firebase-config.js` com suas credenciais.

## Tecnologias

- HTML, CSS, JavaScript puro
- Three.js (versão 3D)
- Firebase (login + contador de guardiões)
- Feito para rodar no navegador

## Por que este projeto

Nascido para comunicar justiça climática de forma lúdica e acessível, conectando a realidade do Acre (cheias, queimadas, extrativismo) à lógica de um jogo — transformar aprendizado em experiência.
