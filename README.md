# Floresta em Pé — Justiça Climática

Site educativo sobre justiça climática no Acre, com simulação "Reserva em Pé".

## O que tem aqui

- **index.html** — site explicativo (justiça climática, El Niño, CadÚnico, Rio Branco)
- **jogo.html / jogo.js / jogo.css** — jogo de simulação 2D (12 anos, 4 personagens)
- **jogo3d.html / jogo3d.js / jogo3d.css** — versão 3D do jogo (Three.js)

## Jogar

Abra o `index.html` no navegador, ou acesse a versão publicada no GitHub Pages.

## Tecnologias

- HTML, CSS, JavaScript puro
- Three.js (jogo 3D)
- Feito para rodar 100% no navegador, sem servidor
